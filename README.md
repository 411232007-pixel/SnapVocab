# SnapVocab 拾物單字簿

在 Discord 頻道上傳生活物品的照片，Bot 會辨識物品，回傳中文、英文、日文的單字卡，並把結果存進你自己的紀錄。可以查歷史、看統計，也能下載只含自己資料的 Excel 單字簿。

需求見 [docs/requirements.md](docs/requirements.md)，設計見 [docs/architecture.md](docs/architecture.md)。

## 需求

- Windows、[uv](https://docs.astral.sh/uv/)（會自動使用 Python 3.12）
- 已登入的 [Claude Code](https://claude.com/claude-code) CLI（`claude -p` 負責圖片辨識與單字卡生成，使用你帳號的額度，不需另購 API 金鑰）
- 一個 Discord Bot，開啟 **Message Content Intent**，並邀請到你的伺服器

## 安裝與設定

```powershell
uv sync
copy .env.example .env
```

編輯 `.env`：

| 變數 | 說明 |
| --- | --- |
| `DISCORD_TOKEN` | Bot Token（不要提交到 git） |
| `CHANNEL_ID` | Bot 唯一監聽的頻道 ID |
| `DB_PATH` | SQLite 檔案位置，預設 `data/snapvocab.db` |
| `LOG_LEVEL` | 預設 `INFO` |

## 啟動

```powershell
uv run python -m snapvocab
```

## 使用方式

使用說明由 Bot 在啟動時發佈並置頂在頻道（需要 Bot 在該頻道有「置頂訊息」或「管理訊息」權限；沒有權限時訊息仍會發出，但要手動置頂）。

| 操作 | 結果 |
| --- | --- |
| 上傳圖片 | 辨識物品並回傳單字卡。一次只辨識一張（同則訊息多張時只處理第一張）；有多個物品或認不出時列出候選按鈕，也可按「其他（自己輸入）」輸入中文名稱 |
| `!最近` | 你最近 10 筆查詢 |
| `!單字 紀錄ID` | 取回指定紀錄的完整單字卡（不重新辨識） |
| `!統計` | 成功查詢次數與不重複單字數 |
| `!匯出` | 傳送只含你自己紀錄的 `.xlsx` |

第一次使用的人，第一張單字卡後會多一行簡短提示。

同一個單字再次查到時，仍會新增一筆紀錄，查詢次數加一，並提示這是第幾次查到。

## 資料與隱私

- 紀錄以 Discord user ID 分開保存，指令只讀取你自己的資料。
- 原圖不寫入磁碟；只保存單字卡的文字資料（`data/snapvocab.db`，已被 `.gitignore` 排除）。
- Excel 以附件傳到指令所在的公開頻道。資料依帳號分開，**不代表附件只有本人看得到**，有頻道權限的人仍可能下載。

## 限制

- 一次處理一張照片中的一個物品；單張上限 8 MB、約 1600 萬像素；PNG、JPEG、WebP、GIF。
- 每人每分鐘 3 次圖片查詢，匯出間隔 30 秒；同時最多 2 個辨識工作。
- 辨識與翻譯由 AI 產生，可能有誤；沒有查證辭典，也不提供辭典來源。
- Bot 是本機行程，電腦關機或睡眠時無法回應。
- `claude -p` 會消耗帳號額度，額度用盡時 Bot 會回覆「暫時無法處理」。

## 展示步驟

1. 啟動 Bot，在指定頻道上傳一張雨傘照片，確認單字卡內容。
2. 再上傳另一件物品，再上傳一次雨傘，執行 `!統計`（查詢次數增加、不重複單字數不變）。
3. 執行 `!最近`、`!單字 紀錄ID`。
4. 執行 `!匯出`，下載並開啟 Excel 檢查兩張工作表。
5. 用第二個帳號重複 1～4，確認兩邊資料互不相同。

`/ready` 與 `/done` 是老師 Scorer 的指令，本 Bot 不實作。
